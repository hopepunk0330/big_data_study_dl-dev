# 다이어그램 레퍼런스 갤러리

이 폴더의 SVG들은 **스타일 참고용**이다 — 겹침 검토·수치 정합성 검증을 여러 차례 거쳐 완성도를 다듬은 결과물이며, 팔레트·폰트 크기 위계·카드/그림자/아이콘 스타일·레이아웃 여백 기준의 예시로 남겨뒀다. 이 하네스가 여러 프로젝트로 포크되면서 서로 다른 프로젝트의 결과물이 함께 쌓인다 — 01~30은 판다스 마케팅 과제, 31~39는 ML(Mercari 가격 예측) 과제 산물이다.

**도메인 내용(할인율·이탈률·LTV, 왜도·전처리 파이프라인 같은 수치·용어)은 그 원본 프로젝트 고유의 것이므로 참고할 필요가 없다.** 새 프로젝트에서 참고할 때는 색·타이포·간격·겹침 방지 기법 같은 "형식"만 보고, 파일에 적힌 실제 숫자나 도메인 용어는 무시한다.

**31~32는 그 이전 카드들에 없는 두 가지를 추가로 보여준다**: (1) `31-price-distribution-boxplot.svg`는 박스플롯(IQR·중앙값 틱·이상치 임계값) 차트 타입과, 아이콘-제목은 최대 16px(GROUP_GAP)로 촘촘히 묶고 서로 다른 섹션·인사이트 박스 사이는 최소 40px(SECTION_GAP)로 확실히 띄우는 간격 위계(근접성 원칙)를 보여준다. (2) `32-preprocessing-pipeline-cascade.svg`는 같은 간격 위계를 3개 섹션이 순서대로 쌓이는 캐스케이드 레이아웃(한 섹션이 늘어나면 그 아래 모든 섹션과 카드 전체 높이가 함께 밀려나는 구조)에 적용한 예시다. 두 값(16px/40px)의 정확한 정의·근거는 `.claude/skills/notebook-toolkit/SKILL.md` E-4절을 따른다 — 이 갤러리는 그 규칙이 실제로 적용된 예시일 뿐, 규칙 자체의 출처가 아니다.

**33~39는 결과보고서(브로셔급 완성도, `docs/reports/`)에서 나온 카드다 — 노트북 카드(01~32)와는 다른 매체(정적 A4 인쇄물)의 관례를 보여준다.** 각 카드는 실제 리포트 산출물(`manuscript.md`의 확정 인라인 SVG 또는 그 직접 전신)에서 그대로 가져왔다 — 도메인 수치는 무시하고 기법만 참고할 것.
- **(1) `33-baseline-comparison-goal-line.svg`**: 목표선(대시 라인)을 막대 rect들보다 **마크업 순서상 나중에** 그려 z-order 상단에 오게 하는 비교 막대+목표달성 배지 패턴 — 막대를 가로질러도 선이 끊기지 않는다.
- **(2) `34-fair-comparison-bracket-grouping.svg`**: "참고 기준 그룹"과 "같은 대상의 전/후 비교 그룹"을 실제 꺾인선(path) 브래킷+라벨로 시각적으로 분리해, 색상 구분만으로는 헷갈릴 수 있는 그룹 관계를 명시하는 패턴.
- **(3) `35-algorithm-concept-dot-pattern.svg`**: 실제 데이터 없이 점(dot) 배치 패턴만으로 알고리즘적 개념 차이(격자탐색=균일 격자점, 무작위탐색=흩어진 점, 베이지안=승자 패널에 점 군집)를 설명하는 스키매틱 카드 — 수치 차트로 담기 애매한 개념을 설명할 때 우선 검토할 유형이다. **이 파일만 예외적으로 `docs/reports/`가 아니라 `ML/assets/cleaned_20-*.svg`(같은 프로젝트의 노트북 결론 카드, 다른 AI 에이전트가 브로셔급으로 재작업한 결과물)에서 가져왔다** — 결과보고서 자체에는 이 패턴의 카드가 없었기 때문이다.
- **(4) `36-shap-interpretation-card.svg`·`39-shap-feature-importance-bars.svg`**: SHAP처럼 해석 기법 자체의 개념(% 기여도 분해, 피처 중요도 순위)을 실제 결과와 함께 보여주는 패턴.
- **(5) `37-multi-round-journey-history.svg`**: 여러 회차(round)에 걸친 시도 이력을 하나의 타임라인/여정으로 압축하는 패턴.
- **(6) `38-dense-comprehensive-summary.svg`**: 여러 핵심 지표·결론을 한 카드에 고밀도로 압축하는 종합 요약 카드(문서 맨 끝 "그래서 결론이 뭔가" 배너용).

사용 규칙은 `.claude/skills/notebook-toolkit/SKILL.md` E-5절(톤앤매너 일관성)을 따른다: 그 노트북 폴더에 참고할 기존 다이어그램이 없는, 완전히 새 프로젝트를 시작하는 상황에서만 이 갤러리를 스타일 기준으로 삼는다. 33~39는 노트북이 아니라 보고서(`docs/reports/`) 작업일 때 우선 참고한다 — `report-writer-contract.md`가 정의하는 A4 인쇄물 관례(박스 없이 페이지에 통합, 넓은 여백 대비 고밀도 등)와 톤이 일치한다.
