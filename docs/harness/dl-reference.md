## ⚠️ 이 문서를 읽는 에이전트가 먼저 알아야 할 것

**1. 내용이 비어 있는 동안은 이 문서를 근거로 삼지 않는다.**
아래 "학습 내용" 절이 비어 있으면 이 프로젝트 고유의 컨벤션은 아직 정해진 게 없다는 뜻이다. 일반 딥러닝 실무 지식으로 답하되 **그것이 일반 지식이라는 점을 사용자에게 밝힌다.** 이 문서가 존재한다는 이유만으로 "프로젝트 컨벤션에 따르면"이라고 말하지 않는다.

**단 `expert-contract.md`의 "사용자 제공 참고 문서 활용" 절이 지시하는 "참고 문서를 만들자고 제안하라"는 이 프로젝트엔 해당 없다** — 그 문서(이 파일)는 이미 존재하고, 채우는 방법은 아래 "이 문서를 채우는 방법" 절에 적혀 있다. 이미 있는 것을 만들자고 제안하지 않는다.

**2. 채워진 뒤에는 이 문서가 교재보다 우선한다.**
`C:\big21\딥러닝 교재`의 교재 PDF(chap01~10)와 사용자가 Notion에 정리한 내용은 **서로 다를 수 있고, 사용자의 정리본이 더 정확할 수 있다.** 사용자가 수업을 들으며 취사선택·보완·정정한 결과이기 때문이다. 따라서:

- **기준(source of truth)은 사용자의 Notion 정리본이다.**
- 교재는 참고자료일 뿐이다. 둘이 어긋나면 **Notion 쪽을 따르고**, "교재에는 이렇게 돼 있다"며 정리본을 반박하지 않는다.
- 어긋나는 지점을 발견하면 임의로 판단하지 말고 사용자에게 알려 확인받는다.

**3. 교재 PDF는 이 저장소의 자산이 아니다.**
저장소 밖(`C:\big21\딥러닝 교재`)에 있고 `.gitignore`의 `*.pdf`로 제외된다. `CLAUDE.md` 금지 항목대로 **읽기 참고까지만 하고 수정·생성·삭제·이동하지 않는다.** 이 문서를 채우는 작업도 교재를 옮겨 적는 게 아니라 사용자의 정리본을 반영하는 것이다.

## 이 문서를 채우는 방법

사용자가 Notion 정리본을 전달하면(페이지 공유·연결 등):

1. `notion-workflow.md`의 읽기 규칙에 따라 해당 페이지를 정독한다.
2. `ml-reference.md`가 한 방식대로 **워크플로우 순서로 재구성**한다 — 노트의 원래 순서를 그대로 베끼는 게 아니라, 실제 작업 순서(환경 → 데이터 → 모델 → 학습 → 평가 → 개선)에 맞춰 재배치한다.
3. **원본 노트의 예제·표현·용어를 최대한 유지한다** — 사용자가 쓰는 말투와 변수명 습관이 그대로 남아야 이 문서의 목적이 달성된다.
4. 아래 표기 규칙으로 검토 지점을 표시한다.
5. 채운 뒤 `HARNESS_LOG.md`에는 적지 않는다(포크 기록 전용). 대신 이 문서 상단의 "상태" 줄을 갱신한다.

### 표기 규칙 (`ml-reference.md`와 동일)

| 표기 | 뜻 |
|---|---|
| **⚠️ 확인 필요** | 노트 내용이 이 프로젝트에 설치된 버전·환경과 어긋나거나, 다시 확인해야 하는 부분 |
| **💡 최신 기법** | 노트에 "잘 안 씀"으로 적힌 기법 옆에, 최근 더 권장되는 대안을 보완 |
| **💭** | 원본 노트가 스스로 "잘 안 씀"이라 표시해둔 부분 — 지우지 않고 그대로 남김 |

## 0. 환경 (실측 — 노트가 아니라 이 저장소에서 확인된 값)

이 절만은 지금 채울 수 있다. 학습 노트가 아니라 **이 저장소에서 직접 확인한 사실**이기 때문이다. 노트가 들어오면 사용자의 환경 구성 습관으로 보완한다.

- **가상환경**: **conda**(Anaconda), 환경 이름 **`dl-dev`** — 사용자가 직접 구성해두었다.
  ```bash
  conda activate dl-dev             # 활성화 (Anaconda Prompt)
  conda list                        # 설치 목록 확인
  # conda 는 PATH에 없다 — 전체 경로로 실행할 수도 있다:
  # C:\Users\mega\anaconda3\envs\dl-dev\python.exe
  ```
- **Python**: 3.11.16. 최신 버전을 기본값으로 삼지 않는다 — 딥러닝 프레임워크는 최신 파이썬 지원이 늦는 경우가 많다.
- **프레임워크**: **PyTorch 2.5.1** / torchvision 0.20.1 / torchaudio 2.5.1, **CUDA 11.8** — 이미 설치돼 있고 `torch.cuda.is_available()`이 True다.
- **GPU**: NVIDIA GeForce GTX 1660 SUPER (**VRAM 6GB**) — 넉넉하지 않다. 배치 크기·중간 텐서 보존을 항상 의식한다.
- **함께 설치된 것**: numpy 2.0.1, pandas 3.0.5, matplotlib, seaborn, scikit-learn 1.9.0, ipykernel. 주피터 커널 `dl-dev` 등록 완료.
- **⚠️ 새 환경을 만들거나 패키지를 설치하기 전에는 `CLAUDE.md` 개발 환경 절의 확인 절차를 반드시 따른다** — `python`·`conda`가 PATH에 없다는 이유로 "설치 안 됨"이라 단정해 중복 환경을 만든 사고가 실제로 있었다.
- **⚠️ PyTorch 설치·재설치·업그레이드(CUDA 빌드 변경 포함)는 수업에서 직접 진행한다 — Claude가 임의로 실행하지 않는다**(`CLAUDE.md` 개발 환경 절).

### 환경 확인 코드

```python
import torch
print("PyTorch:", torch.__version__)
print("CUDA available:", torch.cuda.is_available())
print("CUDA version:", torch.version.cuda)
print("GPU:", torch.cuda.get_device_name(0))
```
