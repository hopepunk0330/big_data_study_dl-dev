# 빅데이터분석기사 필기 레퍼런스

이 문서는 사용자가 학생들과 함께 공부한 "빅데이터분석기사 필기 완벽대비 요약노트"(아답터교육, 개정 2026.08.05, 69페이지)를 재구성한 지식 레퍼런스다. 학생들이 이 요약노트를 기준으로 통계·분석방법론 질문을 해올 수 있으므로, 어떤 프로젝트에서든 그 질문에 정확히 답할 수 있도록 커리큘럼 4과목 구조를 그대로 따라 정리해뒀다. **이 문서는 특정 프로젝트가 여기 나열된 방법론을 반드시 적용해야 한다는 뜻이 아니다** — 프로젝트마다 실제로 어떤 방법을 왜 선택했는지는 각 프로젝트의 계획 문서(`docs/planning/`)와 결과 보고서에 별도로 명시한다. `ml-reference.md`(개인 학습 노트 기반)와 성격이 같은 지식 레퍼런스 문서이며, 절차서(`~-project-workflow.md`류)가 아니다.

## 1과목 — 빅데이터 분석 기획

### 빅데이터의 이해

**데이터·정보·지식·지혜(DIKW 피라미드)**: 데이터(가공 전 객관적 사실) → 정보(데이터를 가공해 패턴을 인식한 것) → 지식(패턴을 의사결정에 활용) → 지혜(지식을 바탕으로 한 창의적 전략). 데이터는 있는 그대로의 "존재적 특성"과 맥락 속에서 의미를 부여받는 "당위적 특성"을 함께 가진다.

**빅데이터의 3V(가트너 정의)와 확장 개념**

| 구분 | 요소 | 의미 |
|---|---|---|
| 기본 3V | Volume(규모) | 데이터 양 증가 |
| | Variety(다양성) | 데이터 유형 증가 |
| | Velocity(속도) | 데이터 생성·처리 속도 증가 |
| 확장 요소 | Value(가치) | 숨겨진 가치 발견이 중요 |
| | Veracity(신뢰성) | 고품질 데이터 |
| | Validity(정확성) | 데이터의 유효성 보장 |
| | Volatility(휘발성) | 데이터의 의미 있는 유지 기간 |

**빅데이터가 만들어내는 변화(4가지)**: 표본조사 → 전수조사, 사전처리 → 사후처리, 질 → 양, 인과관계 → 상관관계.

**데이터 유형(형태 기준)**: 정형(행·열 구조, 관계형DB·CSV 등) / 반정형(메타데이터 포함, HTML·XML·JSON·RDF) / 비정형(구조화되지 않음, SNS·유튜브·음원).

**빅데이터 조직 구조 3종**: 집중 구조(독립 전담 조직, 중복 업무 가능성)·기능 구조(해당 부서가 직접 분석)·분산 구조(분석 인력을 현업 부서에 배치).

### 데이터 산업·기술

**데이터베이스 시스템 핵심 용어**: DBMS(DB 관리·접근 소프트웨어), 스키마(DB 구조·제약조건 명세), 메타데이터(데이터를 설명하는 데이터), 인덱스(정렬·탐색용 보조 도구). SQL은 DDL(CREATE/ALTER/DROP)·DML(SELECT/INSERT/DELETE/UPDATE)·DCL(GRANT/REVOKE)로 구성된다.

**분산 파일 시스템·데이터베이스**

| 구분 | 특징 |
|---|---|
| HDFS | GFS 기반 오픈소스, 마스터노드(네임노드)+슬레이브노드(데이터노드) 구조, 블록 기본 64MB |
| 관계형 DB | 정형 데이터, 무결성 보장(MySQL, Oracle 등) |
| NoSQL | 비정형 데이터, 확장성·가용성 이점 — 키-값(Redis)/열(HBase)/문서(MongoDB)/그래프(Neo4j) |
| 데이터 웨어하우스(DW) | 주제지향성·통합·시계열성·비휘발성(읽기전용) |
| 데이터 마트(DM) | DW의 한 분야, 특정 목적용 소규모 DW |
| 데이터 레이크 | 비정형 데이터를 하둡과 연계해 저장·처리 |

**하둡 생태계**: HDFS(분산 파일 시스템) + MapReduce(Map: Key-Value 변환, Reduce: 집계) 핵심. 서브 프로젝트로 Zookeeper(분산 코디네이터), YARN(리소스 관리), Hive/Pig/Spark(데이터 처리) 등이 있다.

### 개인정보 법제도

**데이터 3법**: 개인정보보호법·정보통신망법·신용정보법.

**개인정보 구분**: 개인정보(동의 필요) / 가명정보(가명처리 후 추가정보 없이는 특정 불가, 통계·연구·공익적 기록보존 목적이면 동의 없이 활용 가능) / 익명정보(더 이상 개인을 알아볼 수 없어 제한 없이 자유롭게 활용). 익명정보는 개인을 특정할 수 없지만, 가명정보는 다른 정보와 결합하면 특정이 가능하다는 게 핵심 차이다.

**개인정보 비식별화 5기법**: 가명처리, 총계처리(평균·라운딩), 데이터 삭제(식별자 삭제), 데이터 범주화(구간으로 변환), 데이터 마스킹(일부를 공백·노이즈로 대체).

**프라이버시 보호 모델**: k-익명성(연결공격 방지) → l-다양성(동질성 공격 방지) → t-근접성(쏠림 공격 방지) 순으로 보호 수준이 강화된다.

### 데이터 분석 계획

**분석 방법론 4단계(Planning→Preparing→Analyzing→Developing→Deploying)**: 분석 기획(비즈니스 이해·범위 설정, SOW·WBS 작성, 위험계획 수립) → 데이터 준비(스토어 설계) → 데이터 분석(EDA·모델링) → 시스템 구현 → 평가 및 전개.

**분석 방법론 비교**

| 방법론 | 절차 |
|---|---|
| KDD | 데이터 선택 → 전처리 → 변환 → 마이닝 → 평가 |
| CRISP-DM | 업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개 |
| SEMMA | 샘플링(Sample) → 탐색(Explore) → 변형(Modify) → 모델링(Model) → 평가(Assess) |

**하향식 vs 상향식 접근**: 하향식은 문제탐색 → 문제정의 → 해결방안탐색 → 타당성 검토 순으로 진행하는 정형화된 접근이고, 상향식은 문제 정의 자체가 어려울 때 비지도학습·프로토타이핑으로 사물을 그대로 인식하는 접근이다. 디자인 싱킹(공감하기 → 문제정의 → 아이디어 도출 → 프로토타입 → 테스트)은 발산(상향식)과 수렴(하향식)을 오가는 혼합 접근이다.

## 2과목 — 빅데이터 탐색

### 데이터 전처리

**척도 구분**: 질적 척도(명목척도·순서척도) vs 양적 척도(등간척도·비율척도, 비율척도만 절대 0이 존재해 사칙연산 가능).

**결측값 3유형**

| 유형 | 정의 | 예 |
|---|---|---|
| MCAR(완전 무작위 결측) | 다른 변수와 무관 | 입력 실수, 전산 오류 |
| MAR(무작위 결측) | 특정 변수와 관련되지만 결과와는 무관 | 특정 정치 성향 유권자의 낮은 응답률 |
| MNAR(비무작위 결측) | 결측치가 변수의 결과와 상관관계 | 소득이 낮은 응답자의 낮은 응답률 |

**결측값 처리**: 완전분석법(삭제)·평균 대치법(비조건부/조건부)·단순 확률 대치법(Hot-Deck/Cold-Deck/Nearest Neighbor)·다중 대치법(여러 번 대치 후 종합, 분산 과소추정 문제 해결 가능).

**이상값 판단 기준**: ESD(평균±표준편차 3배 초과), 사분위수(Q1-1.5×IQR 미만 또는 Q3+1.5×IQR 초과), Z-Score, DBScan(밀도 기반). 이상값을 항상 제거하는 것은 아니다 — 의미 있는 데이터일 수 있다.

**변수 선택 3방법**: 필터(상관계수·카이제곱검정 등 통계적 측정치 활용) / 래퍼(전진선택법·후진제거법 등 모델 성능 기준) / 임베디드(Lasso·Ridge처럼 모델 학습 과정에서 선택).

**차원축소 기법**: 선형(PCA-분산 최대화, LDA-클래스 간 분산 최대화, ICA-독립 성분 탐색, SVD, 요인분석) vs 비선형(MDS, t-SNE, UMAP, AutoEncoder). 차원의 저주(차원이 높아질수록 알고리즘 성능이 저하되는 현상)를 해소하는 것이 목적이다.

**불균형 데이터 처리**: 가중치 균형(Weighted Balance) / 과소표집(UnderSampling — 랜덤·계통·집락·층화 추출법) / 과대표집(OverSampling — SMOTE·ADSYN·ROS).

### 데이터 탐색

**EDA 4대 주제**: 저항성(자료 변동에 민감하지 않음)·잔차 계산(주경향으로부터의 이탈 확인)·자료변수의 재표현(적당한 척도로 변환)·그래프를 통한 현시성.

**상관분석**: 피어슨(양적 척도·연속형 변수·선형관계) vs 스피어만(서열 척도·순서형 변수·선형/비선형 관계). 상관계수는 -1~1 값을 가지며, 상관관계의 정도만 알려줄 뿐 통계적 유의성은 별도 검정이 필요하다.

**첨도·왜도**: 첨도=3이면 정규분포 형태(0을 기준으로 판단하기도 함). 왜도<0이면 최빈값>중앙값>평균값, 왜도>0이면 최빈값<중앙값<평균값 — 평균값은 항상 꼬리를 따라간다.

### 통계기법 이해 — 표본추출

**전수조사 vs 표본조사**: 전수조사는 모집단 전체를 조사(시간·비용 과다 소모), 표본조사는 일부만 추출해 모집단을 분석.

**확률적 표본추출 5방법**

| 방법 | 정의 |
|---|---|
| 단순무작위추출(랜덤 추출법) | 무작위로 표본 추출 |
| 계통 추출법 | 번호를 부여해 일정 간격으로 추출 |
| 집락(군집) 추출법 | 여러 군집으로 나눈 뒤 일부 군집을 통째로 랜덤 선택(군집 내 이질적, 군집 간 동질적 특징 전제) |
| 층화 추출법 | 군집을 나눈 뒤 각 군집에서 추출(군집 내 동질적, 군집 간 이질적 특징 전제) — 비례로 추출하면 비례 층화 추출법 |
| 복원/비복원 추출 | 복원은 추출된 데이터를 다시 포함, 비복원은 제외 |

집락 추출법과 층화 추출법은 "군집 내부가 서로 비슷한가 다른가"를 기준으로 정반대로 구분된다는 점이 자주 헷갈리는 지점이다.

**표본추출법과 무작위 배정(random assignment)은 다른 개념이다.** 표본추출은 "모집단에서 표본을 어떻게 뽑는가"의 문제이고, 무작위 배정은 "이미 모인 표본을 실험군/대조군에 어떻게 나누는가"의 문제다. 위 5가지 확률표집 외에 **비확률표집**(편의표집·판단표집·할당표집 등, 확률적 대표성을 보장하지 않는 방식)도 있으며, 편의표집(convenience sampling)은 접근이 쉬운 대상을 그대로 모으는 비확률표집의 대표적 예다 — 이 요약노트 자체에는 비확률표집이 별도 절로 명시돼 있지 않지만, 확률표집과 대비되는 개념으로 통계학 전반에서 통용된다.

**확률분포**

| 구분 | 종류 |
|---|---|
| 이산 확률분포 | 베르누이·이항·기하·음이항·초기하·다항·포아송 분포 |
| 연속 확률분포 | 균일·정규·표준정규·t·카이제곱·F·지수·감마·베타 분포 |

t분포(표본 30개 미만 소집단의 평균 검정), 카이제곱분포(동질성 검정·모분산 검정), F분포(분산 동일성 검정·ANOVA)는 각각 대응하는 검정 기법과 함께 기억해두면 된다.

**중심극한정리**: 모집단의 분포와 무관하게, 표본크기가 충분히 크면(30개 이상) 표본평균의 분포가 정규분포를 이룬다.

### 통계기법 이해 — 추론통계

**점추정 조건 4가지**: 불편성(추정량의 기댓값=실제 모수)·효율성(분산이 작을수록 효율적)·일치성(표본 크기 증가 시 모수에 가까워짐)·충족성(모집단 정보를 최대한 반영).

**구간추정**: 모분산을 아는 경우 Z분포, 모르는 경우 자유도 n-1인 t분포를 이용해 신뢰구간을 추정한다. 신뢰수준 95%는 Z=1.960, 99%는 Z=2.576.

**가설검정 절차**: (1) 가설 설정(귀무가설 H0=차이 없다, 대립가설 H1=차이 있다) → (2) 검증 방향 결정(대립가설이 "같지 않다"면 양측검정, "크다/작다"면 단측검정) → (3) 검정 방법·표본 유형 결정(모집단 1개=일표본, 2개=이표본, 3개 이상=ANOVA) → (4) 검정통계량 계산과 기각역 판단.

**오류 유형**: 1종 오류(H0가 참인데 기각, 유의수준 α로 관리, 일반적으로 0.05) / 2종 오류(H0가 거짓인데 채택).

**t검정 세부 유형**: 단일표본(모집단 대한 평균검정) / 대응표본(동일 모집단에 대한 평균비교, 예: 같은 사람의 before-after) / 독립표본(서로 다른 모집단 간 평균비교). 독립표본 t검정은 두 집단의 분산이 같다는 등분산 가정이 전제이며, 이 가정이 깨지면 Welch의 t검정을 쓴다.

## 3과목 — 빅데이터 모델링

### 분석모형 설계

**과대적합/과소적합/최적합**: 과대적합(Overfitting)은 모델이 학습 데이터에 지나치게 맞춰져 복잡해진 상태, 과소적합(Underfitting)은 데이터를 충분히 설명하지 못하는 단순한 상태다. 데이터 분할(훈련용/검증용/평가용)은 이 둘을 방지하고 불균형 문제를 해결하기 위해 쓴다 — 훈련용은 학습, 검증용은 과대·과소적합 조정, 평가용은 최종 성능 평가 전용이다.

**분석 도구**: R(통계 분석 특화, 강력한 시각화, 처리속도 느림) vs Python(간결함·높은 가독성, R보다 빠른 처리속도, 상대적으로 약한 시각화).

### 분석기법 — 회귀 계열

**회귀분석 핵심 개념**: 독립변수(원인, x)가 종속변수(결과, y)에 미치는 영향을 파악. 최소제곱법으로 잔차제곱합(SSE)이 최소가 되는 회귀계수를 구한다. 결정계수 R²=SSR/SST=1-SSE/SST(0~1, 회귀모형이 설명하는 변동의 비율).

**회귀분석 종류**: 단순회귀(독립변수 1개) / 다중회귀(2개 이상) / 다항회귀(2차 이상 함수 관계) / 규제항 포함 회귀(릿지=L2 규제, 라쏘=L1 규제, 엘라스틱넷=L1+L2) / 교호항 포함 회귀(변수 간 상호작용 반영).

**선형회귀분석의 4가정**: 선형성·등분산성(오차 분산이 고름)·정규성(오차가 정규분포)·독립성(오차가 서로 독립).

**다중공선성**: 독립변수 간 강한 상관관계가 있을 때 발생 — 상관계수 절댓값 0.8 이상, VIF(분산팽창인수) 10 이상, 조건수 30 이상이면 의심한다. 해결책은 독립변수 제거·차원 축소·변수 선택·규제항 포함 회귀.

**로지스틱 회귀분석**: 종속변수가 범주형(성공/실패)일 때 분류에 활용. 오즈(성공확률/실패확률) → 로짓 변환(오즈에 자연로그) → 시그모이드 함수(0~1 확률로 역변환)의 순서로 구성된다. 회귀계수는 최대우도법으로 추정하고, 모형 전체는 우도비검정(카이제곱검정)으로 검정한다.

### 분석기법 — 분류·군집 계열

**의사결정나무**: 노드 내 동질성이 커지고 노드 간 이질성이 커지는 방향으로 분리하는 화이트박스 모델. 과적합 위험이 높아 정지규칙·가지치기로 방지한다. 분류(범주형) 분할 기준은 CHAID(카이제곱 통계량)·CART(지니지수)·C4.5/C5.0(엔트로피지수)이며, 회귀(연속형)는 CHAID(ANOVA F-통계량)·CART(분산감소량)를 쓴다.

**인공신경망**: 단층 퍼셉트론은 XOR 문제를 풀 수 없어 다층 퍼셉트론(은닉층 삽입)이 등장했다. 활성함수(은닉층: 시그모이드·Tanh·ReLU, 출력층: 시그모이드=이진분류·소프트맥스=다중분류)와 손실함수(MSE=회귀, 크로스엔트로피=분류)를 구분해서 익혀둔다. 과적합 방지에는 규제(L1/L2)·드롭아웃·조기종료·모델 복잡도 감소·데이터 증강·배치정규화를 쓴다.

**서포트벡터머신(SVM)**: 마진(하이퍼플레인과 서포트벡터 사이 거리)이 최대가 되는 하이퍼플레인을 찾는 모델. 커널함수로 저차원 데이터를 고차원으로 변경해 비선형 문제도 다룬다. 하드마진(오류 비허용) vs 소프트마진(어느 정도 오류 허용).

**연관성분석**: 지지도(P(A∩B))·신뢰도(P(A∩B)/P(A))·향상도(P(A∩B)/[P(A)P(B)], 1보다 크면 양의 상관관계) 3지표로 "장바구니 분석"처럼 항목 간 조건-결과 패턴을 찾는다. Apriori 알고리즘(최소 지지도 이하 항목 가지치기)과 FP-Growth 알고리즘(트리 기반으로 반복 탐색 대체)이 대표적이다.

**군집분석**: 계층적 방법(덴드로그램) vs 비계층적 방법(K-means, DBSCAN 등). K-means는 사전에 K를 지정해야 하고 이상치·초기 중심점에 민감한 반면, DBSCAN은 밀도 기반이라 군집 수를 미리 정하지 않아도 되고 노이즈·이상치에 강하다. 거리 측정 방식은 연속형(유클리디안·맨하튼·체비셰프·민코우스키·마할라노비스)과 범주형(잭카드·코사인 유사도)으로 나뉜다.

### 고급 분석기법

**범주형 자료 분석**: 분할표(교차표)를 활용한 적합도 검정(관측 데이터가 특정 분포에 적합한지)·독립성 검정(두 변수 간 독립성)·동질성 검정(두 집단 이상이 동일 분포를 따르는지) — 셋 다 카이제곱 검정을 활용한다.

**다변량 분석**: ANOVA(여러 집단 평균 비교, 일원=요인 1개/이원=요인 2개/MANOVA=다수 요인+다수 종속변수), 요인분석(변수들을 소수의 잠재 요인으로 축약, 요인추출은 주성분분석이 가장 많이 쓰임).

**시계열 분석**: 정상성(모든 시점에서 평균·분산이 일정)을 만족해야 예측이 가능하며, 차분·로그변환 등으로 정상시계열로 변환한다. AR(자기회귀, 과거 값이 미래를 결정, PACF로 차수 p 선정)·MA(이동평균, 과거 백색잡음의 선형결합, ACF로 차수 q 선정)·ARIMA(p,d,q)(AR+MA 결합, d=차분 횟수) 순으로 이해하면 된다. 계절성이 있으면 SARIMA를 고려한다.

**앙상블 분석**: 보팅(다수결)·배깅(부트스트랩 복원추출 후 보팅, 랜덤포레스트가 대표적, 편향은 높지만 분산 감소로 과적합에 강함)·부스팅(잘못 분류된 데이터에 가중치를 주는 방식, AdaBoost·GBM·XGBoost·LightGBM)·스태킹(여러 모델의 예측을 메타 학습기로 다시 학습). 보팅·배깅·랜덤포레스트는 병렬처리가 가능하지만, 부스팅은 순차적 특성상 병렬처리가 불가능하다.

**비모수 통계**: 모집단 분포를 가정할 수 없을 때 관측값의 순위·차이로 검정한다 — 부호검정·순위합검정·만-휘트니 U검정·크러스칼-월리스 검정·프리드먼 검정 등. 이 프로젝트(Mercari) 실험설계서의 가격 편차 분석에 쓰인 Wilcoxon signed-rank 검정(대응표본 비모수)도 이 범주에 속한다.

## 4과목 — 빅데이터 결과해석

### 분석모형 평가

**분류모델 평가지표(혼동행렬 기반)**

| 지표 | 계산식 | 의미 |
|---|---|---|
| 정밀도(Precision) | TP/(TP+FP) | 양성 예측 중 실제 양성 비율 |
| 재현율(Recall, 민감도) | TP/(TP+FN) | 실제 양성 중 예측 성공 비율 |
| 특이도(Specificity) | TN/(FP+TN) | 실제 음성 중 예측 성공 비율 |
| 정확도(Accuracy) | (TP+TN)/전체 | 전체 중 예측 성공 비율 |
| F1 Score | Precision·Recall의 조화평균 | 두 지표 간 트레이드오프를 종합 |

ROC 커브(가로축 1-특이도, 세로축 민감도)의 AUC는 0.5~1 사이이며 1에 가까울수록 좋은 모델이다.

**회귀모델 평가지표**: MSE·MAE·RMSE(=√MSE)·MAPE·MPE 같은 손실함수 계열과, 결정계수(R²)·수정된 결정계수(변수 개수를 감안, 다중회귀에서는 이쪽을 일반적으로 사용)가 있다. 이 프로젝트(Mercari)가 공식 평가지표로 쓰는 **RMSLE**는 이 요약노트에 별도 항목으로 없지만, RMSE와 같은 계열(오차 크기 지표)에 속하며 로그 변환 후 RMSE를 취하는 방식으로 이해하면 된다.

**과대적합/과소적합 진단**: 과대적합은 높은 분산·낮은 편향, 과소적합은 낮은 분산·높은 편향 — 분산과 편향의 트레이드오프를 확인해 최적 모델을 선정한다.

**교차 검증**: 홀드아웃(한 번만 분할) / K-fold(k개 집단으로 나눠 k-1개 학습·1개 검증) / LOOCV(1개씩 검증, 신뢰도는 높지만 연산량 과다) / 부트스트래핑(복원추출로 데이터 부족·불균형 문제 해소).

**적합도 검정**: Q-Q plot(정규성을 분위수로 시각 확인, 점이 45도 대각선에 가까울수록 정규성 존재) / 카이제곱 검정 / 샤피로-윌크 검정 / 콜모고로프-스미르노프 검정.

**모수 유의성 검정**: 전제 조건은 정규성(Shapiro-Wilk)·등분산성(Levene·F검정)·독립성(더빈-왓슨 검정). 검정 종류는 Z검정(표본이 모집단에 속하는지)·t검정(평균 비교, 단일/독립/대응표본)·F검정(분산 동일성)·ANOVA(3집단 이상 평균 비교).

### 분석모형 개선

**과대적합 방지 4관점**: 데이터(양 증가·증강·피처선택·차원축소) / 규제(L1·L2) / 모델 알고리즘(드롭아웃·가지치기) / 학습 프로세스(교차검증·조기종료). 학습곡선(Epoch에 따른 훈련/검증 오차 시각화)에서 검증 오차가 다시 증가하기 시작하는 지점이 학습을 종료해야 할 시점이다.

**매개변수 vs 하이퍼파라미터**: 파라미터는 학습을 통해 최적화되는 값(수동 설정 불가), 하이퍼파라미터는 사용자가 수동으로 설정하는 값(최적의 파라미터를 도출하기 위한 조건).

**하이퍼파라미터 탐색 방법 4종**: Manual Search(경험·감으로 설정) / Grid Search(모든 조합 탐색) / Random Search(임의 탐색) / Bayesian Optimization(모델링을 통해 최적 조합 발견). 이 프로젝트(Mercari)의 HPO 3종 비교(GridSearchCV/RandomizedSearchCV/Optuna)가 이 세 축(전수·무작위·베이지안)을 그대로 실무에 적용한 사례다.

**경사하강법 옵티마이저 계보**: GD/SGD → Momentum(이동 방향의 관성 반영) → Adagrad(누적 기울기로 학습률 자동 조정) → RMSProp(지수이동평균으로 학습률 조절)·NAG(관성 방향으로 미리 이동) → Adam(Momentum+RMSProp 결합)·NADAM(NAG+RMSProp).

### 분석결과 해석·시각화·활용

**시각적 자료 해석 요령**: 박스플롯은 분산·중앙값·이상치를 보여주지만 평균은 알 수 없다. 히트맵은 상관관계 강도를 색으로 보여주며, 강한 상관관계가 관찰되면 다중공선성 발생 가능성을 함께 점검한다(PCA 등으로 대응).

**주성분분석(PCA) 결과 해석**: 누적 설명력(Cumulative Proportion)이 70~90%가 되는 지점까지 주성분을 채택하는 것이 일반적이며, 스크리플롯에서 기울기가 완만해지는(elbow) 직전 지점의 개수를 선택 기준으로 삼는다 — 다만 이 선택은 절대적 기준이 아니라 연구자의 판단 영역이다.

**시각화 유형 분류**: 시간(막대·점·선·경사·영역 차트) / 공간(단계구분도·카토그램·버블플롯맵) / 관계(산점도·버블차트·덴드로그램·히트맵·상관도표) / 비교(버터플라이·스타차트·체르노프 페이스·평행좌표) / 분포(히스토그램·파이차트·박스플롯·모자이크차트·트리맵).

**인포그래픽**: 데이터 시각화가 패턴 발견이 목적이라면, 인포그래픽은 일반 대중에게 설득형 메시지를 전달하는 것이 목적이라는 점에서 다르다. 원 데이터(Raw Data)를 그대로 쓰지 않고 가공을 거친다는 점도 데이터 시각화와의 차이다.

## 참고 — 이 프로젝트(Mercari)의 실제 선택과 이 커리큘럼의 대응 관계

**이 절만은 이 문서의 나머지 부분(1~4과목 커리큘럼 요약)과 성격이 다르다 — 포터블 지식이 아니라 이 프로젝트 고유의 사례다.** 위 1~4과목 내용은 어느 프로젝트로 이식하든 그대로 재사용하지만, 이 표는 "이 개념이 실무에서 어떻게 구체화되는지" 감을 잡기 위한 Mercari 프로젝트 한정 예시일 뿐이다. `git-workflow.md` 2절이 `CLAUDE.md`를 다루는 것과 같은 방식으로 취급한다 — **하네스를 새 프로젝트로 포크할 때, 이 표는 그대로 복사해오지 말고 그 프로젝트의 실제 선택으로 다시 채우거나(그 프로젝트가 이런 대응 사례를 아직 안 가지고 있다면) 절 자체를 비워둔다.** 아래는 이 노트를 앞으로 다른 프로젝트에서도 빠르게 훑어볼 때 참고할 수 있도록, Mercari 프로젝트가 실제로 어떤 개념을 어떻게 적용했는지 대응시킨 예시다(이 문서 자체가 강제하는 규칙이 아니라, 위 개념들이 실무에서 어떻게 구체화되는지 보여주는 사례).

| 이 노트의 개념 | Mercari 프로젝트의 실제 선택 |
|---|---|
| 표본추출법 | AB테스트 참여자는 편의표집(카카오톡 개인 발송) — 확률표집이 아님을 결과보고서에 명시 |
| 무작위 배정 | AB테스트 순서 배정은 순수 무작위가 아니라 블록 랜덤화(SRM 사전 방지) |
| 규제항 포함 회귀 | 최종 승자 모델이 Ridge(L2 규제) — alpha를 HPO 3종으로 튜닝 |
| 하이퍼파라미터 탐색 3방법 | GridSearchCV·RandomizedSearchCV·Optuna(베이지안)를 공정 조건에서 비교 |
| 회귀모델 평가지표 | RMSLE(가격의 로그 오차)를 공식 지표로 채택, R²는 보조 지표로 병기 |
| 비모수 검정 | 가격 편차(비수용 시 희망가) 비교에 Wilcoxon signed-rank 검정 사용 |
| 이항검정·McNemar | AB테스트 1차 지표(선호율)·보조 지표(가격 수용도) 검정에 사용(이 요약노트의 4과목 범주형 자료 분석과 같은 계열) |
